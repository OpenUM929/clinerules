# 관리자 설정 — API 관리 탭

> 소속 메뉴: [관리자 설정 (mngr_sett)](05-mngr-sett.md) · 탭 ⑥

## 조작 절차

### API 키 목록 조회

**목적:** 등록된 API 키 목록을 조회합니다.

**조작 절차:**
1. API 관리 탭 선택
2. 페이징 또는 검색어 입력
3. 목록 확인

**확인 항목:** 코드, 만료일, 담당자 이메일, 상태

### API 키 등록/수정

**조작 절차:**
1. 등록 버튼 클릭
2. 코드, 만료일, 담당자 이메일 입력
3. 저장 버튼 클릭

**주의사항:** 만료일이 지난 API 키는 알림 대상이 됩니다.

### API 키 삭제

**조작 절차:**
1. 대상 행 선택
2. 삭제 버튼 클릭
3. 확인 다이얼로그에서 확인

### 만료 알림 설정

**목적:** API 키 만료 전 메일 알림을 설정합니다.

**알림 기준:**

| 기간 | 발송 시점 |
|------|----------|
| 30일 전 | 1회 발송 |
| 7~1일 전 | 매일 발송 |
| 당일 | 1회 발송 |

### 메일 테스트

**조작 절차:**
1. 테스트 메일 발송 버튼 클릭
2. SMTP 연결 및 발송 결과 확인
