## 2. 관리자 설정(mngr_sett) 작성 특이사항

`05-mngr-sett.md`는 정보가 방대하므로 별도 파일(탭 하위파일 방식, [../../common/operator-manual/DEVELOPMENT/05-composition-nav.md](../../../../common/operator-manual/DEVELOPMENT/05-composition-nav.md))로 관리한다.

### 2.1 추가 섹션 구조
| 섹션 | 내용 |
|------|------|
| 10. API 관리 | API 키 등록/수정/조회, 만료일 관리, 메일 테스트 |

### 2.2 API 관리 상세
- **10.1 API 키 목록 조회**: 페이징·검색, 코드/만료일/담당자 확인.
- **10.2 API 키 등록/수정**: 코드·만료일·담당자 이메일 입력, 저장 시 유효성 검사.
- **10.3 API 키 삭제**: 선택 삭제, 일괄 삭제.
- **10.4 만료 알림 설정**: 30일 전/7일 전/당일 메일 발송, 메일 스케줄.
- **10.5 메일 테스트**: 테스트 메일 발송, SMTP 연결 확인.
