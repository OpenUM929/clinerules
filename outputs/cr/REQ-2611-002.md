### 변경 배경 / 이유
> 통합데이터 생성(배치) 화면 데이터 업로드 영역(`#fileUploadArea`)에 파일을 끌어다 놓으면 브라우저 기본 동작(파일 열기)이 일어나고 업로드되지 않음. 29_01 #5 에서 고쳤던 기능의 회귀.

### 변경 전 → 변경 후
- Before: 업로드 영역은 클릭(파일 선택 창)만 지원, 드롭 시 기본 동작 미차단·업로드 없음
- After : dragenter/dragover/dragleave/drop 에 `preventDefault` + `.dragover` 클래스 토글. drop 시 csv/xlsx/xls 만 허용(그 외 안내창 후 중단), `DataTransfer` 로 `fileInput.files` 에 넣고 `change` 이벤트를 발생시켜 기존 업로드 경로(`/api/batch/upload`) 재사용

### 영향 범위
> 배치 화면 업로드 영역 프런트엔드만. 서버 API·업로드 처리 로직 변경 없음(기존 change 핸들러 경로 재사용).

**변경 코드 요약:**
```javascript
// Before
fileUploadArea.addEventListener('click', function() { ... fi.click(); });
// (드래그 앤 드롭 처리 없음)

// After
['dragenter', 'dragover'].forEach(function(ev) {
    fileUploadArea.addEventListener(ev, function(e) {
        e.preventDefault();
        fileUploadArea.classList.add('dragover');
    });
});
['dragleave', 'drop'].forEach(function(ev) {
    fileUploadArea.addEventListener(ev, function(e) {
        e.preventDefault();
        fileUploadArea.classList.remove('dragover');
    });
});
fileUploadArea.addEventListener('drop', function(e) {
    var files = e.dataTransfer && e.dataTransfer.files;
    if (!files || files.length === 0) return;
    if (!/\.(csv|xlsx|xls)$/i.test(files[0].name)) { alert(...); return; }
    var dt = new DataTransfer();
    dt.items.add(files[0]);
    fi.files = dt.files;
    fi.dispatchEvent(new Event('change'));
});
```
