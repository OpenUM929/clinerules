### 변경 사항 요약
> 사내 보안 프로그램의 확장자 단위 파일 일괄 삭제(html/txt/csv/png) 사고 재발에 대비해, 점검·복원 도구와 세션 시작 자동 감지 훅을 추가했다.

### 상세 변경 사항
**1. 삭제 점검·복원 도구 (dlp_guard.ps1)**
- 기본 실행: 본체 + `.clinerules` 서브모듈 양쪽에서 삭제된 추적 파일과 git 이 못 지키는 무방비 자산(미추적/무시)을 감시 확장자(html/txt/csv/png) 기준으로 보고. 삭제 발견 시 종료코드 1
- `-Restore`: 삭제된 추적 파일만 HEAD 에서 복원(수정 중인 파일은 건드리지 않음)
- `-Snapshot`: git 이 못 지키는 대상을 스윕 확장자 밖의 `.dlpbak`(zip 위장) 아카이브로 백업

**2. 세션 시작 자동 점검 훅**
- `.claude/settings.json` 의 SessionStart 훅이 매 세션 시작 시 `dlp_guard.ps1 -Hook` 을 실행
- 평시엔 무출력, 삭제가 발견된 경우에만 경고 메시지 + 복원 안내 표시

**3. 대응 절차 지침화**
- `CLAUDE.md` 에 사고 요약·복원 명령·신규 산출물 확장자 원칙(생존이 실측된 확장자만 사용: txt→md, csv→jsonl, png→svg / html·csv 처럼 못 바꾸는 것은 생성 즉시 커밋 또는 `-Snapshot`) 신설
