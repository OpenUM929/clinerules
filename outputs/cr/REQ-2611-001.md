### 변경 배경 / 이유
> 사용자 요청 3건(2026-11-02): ① 결과물 관리에서 제출용 저장(ZIP) 1회가 직원 수만큼 수십 행으로 펼쳐짐 → 1행으로 ② 저장 갤러리에 워드클라우드 생성에 쓰인 문장·선택 단어 정보가 없음 → 「상세 정보」 옆에 「관련 평가 보기」 탭 ③ 전사 욕설 리스트에서 「이름」 열 삭제.

### 변경 전 → 변경 후
- Before: 묶음 키 `COALESCE(group_key, id)` → 제출용 저장·「그래프 포함」 그래프가 직원마다 1행 / 목록 응답에 묶음의 `entry_ids` 전부 적재, 다운로드·삭제는 화면이 보낸 id 목록으로 처리 / 저장 갤러리는 이미지·상세 정보만, 단어·문장 기록 없음 / 욕설 리스트 화면·CSV 에 이름 열과 「직원명」 정렬
- After : 묶음 키 `COALESCE(group_key, NULLIF(batch_title,''), id)` → 저장 1회 1행(명칭 없는 매트릭스는 종전대로 엔트리별), 응답에 id 미적재·`employee_count` 추가, 다운로드·삭제·명칭 수정은 `bundle_keys` + 조회 시점 고정 필터로 서버가 해결, 삭제는 화면 건수(`expected_count`)와 다르면 409, 묶음 ZIP 임시 파일 응답 후 삭제·PNG 무압축 / 제출용 저장 시 `gallery_evidence`(zlib JSON)에 워드클라우드 실제 선택 단어·문장 기록, 관리자 전용 `GET /deploy-gallery/evidence/<entry_id>`, 단어-문장 매칭은 Kiwi 형태소 경계(「자세」≠「자세히」) / 욕설 리스트 이름 열·「직원명」 정렬·CSV 이름 열 제거

### 영향 범위
> 결과물 관리 게시판(`output_board`) 목록·다운로드·선택/전체 삭제·명칭 수정, 저장 갤러리(`deploy_gallery`) 모달, 제출용 저장(`save_to_deploy`) 기록 단계, 욕설 리스트 2개 화면과 CSV. `deploy_sessions.db` 에 신규 테이블 `gallery_evidence` 추가(기존 `gallery_entries` 스키마 불변). 과거 저장분도 명칭 키라 즉시 1행으로 보이며(재기록 불필요), 과거 제출용 저장분의 「관련 평가 보기」는 기록이 없어 안내 문구만 나온다. 감정 판정 규칙·가명 처리 변경 없음. 서버 재시작 필요.
