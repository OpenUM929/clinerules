### 변경 요약 (1줄, 50자 이내)
> 연도별 긍정/부정 추이 라인 그래프 PNG 생성 + 「그래프 저장」 버튼 구현

### 변경 배경 / 이유
> 인사처 납품물은 직원별 **긍정 워드클라우드 · 부정 워드클라우드 · 연도별 긍/부정 추이 그래프** 3종이다.
> 앞의 2종은 「제출용 저장」이 이미 생성했지만 추이 그래프는 시스템에 존재하지 않았다
> (긍/부 비율 표시는 매트릭스 셀 내부 CSS 막대뿐, 라인 차트 코드 0건).

### 변경 전 → 변경 후
- Before: 연도별 추이를 볼 수 있는 화면·파일 없음. `save_to_deploy` 는 선택 연도를 하나로 합쳐 1세트만 생성
- After : 선택 연도별로 긍정/부정을 집계해 라인 차트 PNG 를 `outputs/배포/그래프/<이름_사번>_긍부정그래프.png` 로 저장.
  지표 5종 × 단위 2종 선택, 단건·CSV 다건·전체 일괄, ZIP 포함, 갤러리 「그래프」 탭 노출

### 영향 범위
> 기존 「제출용 저장」·매트릭스 저장 경로는 **무변경**(`perspective_service.py` 는 +402 / −0). 감정 판정 로직
> (`_get_sentence_level_scores`, `calculate_word_scores`)과 단어 극성 경계(`>= 0` / `< 0`)는 손대지 않았다 —
> 긍↔부 오분류 방지 잠금 규칙. 갤러리 `gallery_entries` 는 `images` JSON 에 `graph` 키를 더할 뿐 스키마 변경 없음.

**핵심 설계 (지표 → 산식):**

```
sentence_cnt (기본) : 문장 점수 > 0 개수 / < 0 개수      (중립 0 은 양쪽 모두 제외)
word_freq           : 극성별 단어 빈도 합
word_uniq           : 극성별 단어 종류 수
word_weighted       : Σ(빈도 × |단어 점수|)
sentence_power      : Σ|문장 점수|
단위 pct            : 값 / (긍정+부정) × 100            (분모에 중립 없음)
```
