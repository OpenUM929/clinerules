### 변경 요약 (1줄, 50자 이내)

사내 보안 사고 대응: DLP 도구 이전 + SessionStart 훅 설정 템플릿 추가

### 변경 배경 / 이유

2026-08-20 사내 DLP(Data Loss Prevention) 프로그램이 `.html/.txt/.csv/.png` 확장자 파일을 확장자 단위로 전량 하드 삭제했다(wordcloud 프로젝트 기준 본체 61개 + .clinerules 56개). `.git` 내부는 무사했으나, git이 추적하지 않는 자산(예: 생성된 보고서, 이미지)은 완전 손실되었다.

이를 대비하기 위해:
1. PowerShell 기반 점검·복원 도구(`dlp_guard.ps1`)를 .clinerules에 중앙 배치
2. 모든 프로젝트가 공용으로 쓸 수 있게 프로젝트 이름 하드코딩 제거
3. SessionStart 훅 설정 템플릿(`.claude/settings.json`)으로 매 세션 시작 시 자동 점검
4. 도구 문서화(tools/README.md) 추가

### 변경 전 → 변경 후

- **Before**: 각 프로젝트가 개별적으로 DLP 대비 도구 보유 (wordcloud_project/scripts/dlp_guard.ps1)
- **After**: .clinerules 중앙 배치 + 자동 훅 적용 + 통합 문서화

### 영향 범위

- `.clinerules` 저장소에만 영향 (모든 서브모듈 프로젝트에서 공용으로 사용)
- SessionStart 훅: wordcloud 본체에서 `.claude/settings.json` 복사 시 자동 적용
- 기존 프로젝트별 커스터마이즈는 `.dlp_guard.json`으로 지원

**변경 코드 요약:**

```powershell
# tools/dlp_guard.ps1 (신규 파일)
# 기본 모드: 삭제된 추적 파일 + git이 못 지키는 무방비 자산 보고
powershell -NoProfile -File .clinerules/tools/dlp_guard.ps1

# 복원 모드: HEAD에서 삭제분만 복원 (수정된 파일은 건드리지 않음)
powershell -NoProfile -File .clinerules/tools/dlp_guard.ps1 -Restore

# 백업 모드: 스윕 대상 확장자 파일을 .dlpbak으로 아카이브
powershell -NoProfile -File .clinerules/tools/dlp_guard.ps1 -Snapshot
```
