### 변경 요약 (1줄, 50자 이내)
> 사내 보안 프로그램의 확장자 일괄 삭제 대비 점검·복원 도구(dlp_guard.ps1) + 세션 시작 자동 점검 훅 추가

### 변경 배경 / 이유
> 2026-08-20 사내 보안 프로그램이 `.html`/`.txt`/`.csv`/`.png` 확장자를 **전량 하드 삭제**(휴지통 우회)하는 사고가 발생했다. 본체 61개 + `.clinerules` 서브모듈 56개가 삭제되었고 전부 git HEAD 에서 복원 완료했다. 정책상 재발이 예상되어, 삭제를 조기 발견하고 즉시 복원할 수 있는 상시 점검 도구와, 재발생 시 못 지키는 자산(미추적/무시 파일)을 백업하는 수단이 필요했다.

### 변경 전 → 변경 후
- Before: 확장자 단위 삭제를 감지·복원하는 수단이 전혀 없었다. 삭제가 발생해도 세션 중 인지하지 못하고, 복원은 수동으로 `git checkout` 대상 파일을 일일이 찾아야 했다.
- After : `dlp_guard.ps1` 이 본체 + `.clinerules` 서브모듈 양쪽을 감시 확장자(html/txt/csv/png) 기준으로 점검한다. 기본 실행은 삭제된 추적 파일과 git 이 못 지키는 무방비 자산(미추적/무시)을 보고(삭제 발견 시 종료코드 1), `-Restore` 는 삭제된 추적 파일만 HEAD 에서 복원(수정 중인 파일 불가침), `-Snapshot` 은 못 지키는 자산을 스윕 대상 밖 확장자(`.dlpbak`)로 위장한 zip 아카이브에 백업한다. `.claude/settings.json` 의 SessionStart 훅이 `-Hook` 모드를 세션마다 자동 실행해, 평시엔 무출력·삭제 발견 시에만 경고(JSON systemMessage + additionalContext)를 낸다. `CLAUDE.md` 에 사고 요약·복원 명령·신규 산출물 확장자 원칙(생존이 실측된 확장자만: txt→md, csv→jsonl, png→svg / html·csv 처럼 못 바꾸는 것은 생성 즉시 커밋 또는 `-Snapshot`)을 신설했다.

### 영향 범위
> 신규 파일 2건(스크립트·훅 설정) + 기존 `CLAUDE.md` 1개 절 추가뿐이며, 앱 런타임 코드(`wordcloud_project/src`, `web/`)는 무변경. `.claude/settings.json` 은 세션 시작 시 PowerShell 프로세스 1회(타임아웃 30초, 실패 시 `|| true` 로 세션 진행에 영향 없음)를 추가한다. 원데이터·PII 는 다루지 않는다(DL-9 해당 없음).

```json

  "hooks": {
    "SessionStart": [
      { "hooks": [ {
        "type": "command",
```
