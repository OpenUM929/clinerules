# 04. A4 페이지·인쇄 규칙 (→ 00 정본을 따른다)

> 나침반: [../DEVELOPMENT.md](../DEVELOPMENT.md) · **정본: [00-a4-authoring-guide.md](00-a4-authoring-guide.md)**

> 🔴 **A4 양식·페이지 구성·마크업의 정본은 [00-a4-authoring-guide.md](00-a4-authoring-guide.md) 이다.** 아래는 작성 시 반드시 지킬 핵심만 옮긴 요약이며, 상세·근거·엔진 동작은 00 정본 §1~§5를 본다. 충돌 시 무조건 00.

---

## 1. 페이지 나눔은 `---pb---` 만 쓴다 (00 §2-2)

- 수동 페이지 나눔 토큰은 **`---pb---`**(한 줄 단독, 위아래 빈 줄). 자동 나눔에 맡기지 않는다.
- ❌ **`<!-- pagebreak -->` / `<div class="pagebreak">` 폐기** — md_editor(Tiptap)가 인식하지 못하고 떨궈낸다. (구 `print.css` 파이프라인 전용 마커였음, 06 레거시.)
- 주제 경계마다 직접 넣어 자동 나눔(들쭉날쭉 경계)이 생기지 않게 한다.

## 2. 한 블록 ≤ 한 페이지 (00 §3-2)

| 여백 프리셋 | 여백 | 인쇄 가능 **높이** | 인쇄 가능 **폭** |
|------|------|------|------|
| 매우좁게(기본) | 20mm | **257mm** | 170mm |
| 좁게 | 30mm | 237mm | 150mm |
| 중간 | 40mm | 217mm | 130mm |

- 표·이미지·코드블록 하나가 위 '높이'를 넘지 않게. 넘는 표는 논리적 지점에서 여러 표로 나누고 **머리행 반복** 후 사이에 `---pb---`.
- 거의 한 페이지 높이인 큰 이미지는 앞뒤에 `---pb---` 로 **단독 페이지**(00 §3-3).

## 3. 이미지·표는 픽셀 폭 속성을 쓰지 않는다 (00 §2-5)

- ❌ `<img width="800">` 등 픽셀 폭 → 인쇄 가능 폭(기본 170mm) 초과로 옆으로 넘침.
- ✅ `![대체텍스트](경로)` — `reportTheme` 가 `max-width:100%` 로 자동 맞춤. 이미지 파일 실재 반드시 확인(없으면 높이 0 → 페이지 계산 어긋남).
- 표는 `table-layout: fixed` 로 폭 균등 분배. 컬럼 수를 A4 폭 안에서 제한.

## 4. 작성 검증

- 높이 추정은 ±1장 흔들리므로, **분리(bunri) 모드 스크린샷**으로 페이지별 주제 완결·넘침·공백을 보고 `---pb---` 위치를 확정한다(00 §5-5 실측 미세조정).
