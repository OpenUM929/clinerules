# 02. 이미지 캡처 규칙 (요소 단위 · Playwright)

> 나침반: [../DEVELOPMENT.md](../DEVELOPMENT.md) · 삽입·폴더 규약 정본: [00-a4-authoring-guide.md](00-a4-authoring-guide.md) §2-5·§2-6

> 🔴 **이미지 삽입 문법·크기·폴더 배치는 [00-a4-authoring-guide.md](00-a4-authoring-guide.md) 를 따른다.** 본 문서는 **무엇을·어떻게 캡처하는가**(요소 단위·Playwright)를 다룬다. 삽입은 `![]()` 표준 마크다운만(§2), 픽셀 폭·`<div style>` 금지.

---

## 1. 캡처 원칙 (요소 단위 필수)

- **설명 대상 = 이미지 1장 (필수)**: 표의 구성·형태, 차트, 메뉴, 입력 폼, 버튼군 등 **설명하는 모든 대상**에 그 대상만 담은 이미지를 붙인다. **설명 텍스트만 있고 이미지가 없는 항목은 미완성**(체크리스트 [07-checklist.md](07-checklist.md)).
- **요소만 잘라 캡처(element clip)**: 전체 화면을 넣지 말고 **해당 요소만** 캡처. 전체 화면은 화면 구성 상단 **구조 파악용 1장에 한해 선택**.
- **캡처는 Playwright로**(아래 §3): 요소 셀렉터를 지정해 그 요소만 스크린샷. 본문 표에 적은 `#id`(예: `#display-mode-selector`, `#viewModeToggle`)를 캡처 셀렉터로 재사용.
- **화살표/번호**: 설명 대상에 빨간 원/화살표(요소 캡처 후 주석 오버레이).
- **민감 정보 마스킹**: 비밀번호·API 키·개인정보는 흐리게.

---

## 2. 이미지 삽입 방법 (표준 마크다운만 · 00 §2-5·§2-6)

```markdown
![설명](img.<문서명>/파일명.png)
```

- ✅ **`![대체텍스트](경로)` 표준 마크다운만.** 크기·테두리·정렬은 `reportTheme`(CSS)가 담당한다.
- ❌ `<img src ... width=...>` · `<div style="border...">` 등 **HTML 이미지 삽입 금지** — md_editor(Tiptap)가 떨궈내거나 픽셀 폭이 인쇄 폭(170mm)을 넘겨 옆으로 샌다(00 §2-5).
- **폴더 규약(00 §2-6):** 문서 `X.md` 의 이미지는 같은 폴더의 **`img.X/`**(X=확장자 제외 파일명) 하위에 두고 **상대경로**로만 참조한다. 워크스페이스는 **경로 입력(path mode)** 으로 연다(안 그러면 상대경로가 404).
  - 참고: 기존 매뉴얼의 공용 `images/` 폴더 방식은 **레거시**다. md_editor 렌더로 전환하는 문서는 `img.<문서명>/` 로 이관한다(00 §2-6).
- 큰 이미지(거의 한 페이지 높이)는 앞뒤에 `---pb---` 로 **단독 페이지**에 둔다(00 §3-3).

---

## 3. Playwright 요소 캡처 절차 (필수 방법)

**Playwright**(브라우저 자동화, MCP 또는 스크립트)로 요소 단위 캡처한다. 전체 화면을 찍어 편집기로 자르지 말 것.

1. **로컬 서버로 대상 페이지 열기**(서버 실행은 사용자 승인 하에).
2. **캡처할 요소 셀렉터 지정** — 본문 표의 `#id`/CSS 셀렉터 그대로.
3. **요소 스크린샷**: 렌더 완료 대기 후 **그 요소만** 캡처.
   ```js
   await page.locator('#display-mode-selector').screenshot({ path: 'images/06-card-summary-display-mode.png' });
   // 표/차트 영역은 컨테이너 셀렉터로, 잘림 방지 위해 요소 스크린샷 권장
   ```
   MCP: 페이지 열기 → 요소 참조 선택 → 요소 스크린샷 저장.
4. **저장 위치·파일명**: 문서 `X.md` 와 동일 폴더의 **`img.X/`** + `{메뉴ID}-{영역/기능}.png`(00 §2-6). 참조는 상대경로 `![](img.X/…png)`.
5. **A4 규칙**: 삽입은 `![]()` 만(픽셀 폭 속성 없음). 원본 캡처가 인쇄 폭(170mm)에서 과축소되지 않도록 **요소만** 좁게 캡처(글자 가독성 확보). 거의 한 페이지 높이면 앞뒤 `---pb---` 로 단독 페이지([04-a4-print.md](04-a4-print.md), 00 §3-3).
6. **민감정보 마스킹** 후 커밋.

> **커버리지 원칙**: "이 표/차트/메뉴/폼을 설명했는데 그 요소 이미지가 있는가?"를 항목마다 자문. 없으면 체크리스트 불충족.

---

## 4. 캡처 영역 예시

| 메뉴 | 캡처 대상 영역 |
|------|---------------|
| 대시보드 | 상태 요약 패널, 알림 영역, 차트 범례 |
| 수집 스케줄 | 필터 패널, 상태 뱃지, 상세 보기 버튼 |
| API 키 관리 | 등록 폼, 만료일 달력, 메일 테스트 버튼 |
| 사용자 관리 | 권한 체크박스 그룹, 데이터 권한 트리 |
| 관리자 설정 | 코드/색상 선택기, 아이콘 업로드 영역 |
