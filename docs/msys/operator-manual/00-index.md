# MSYS 운영자 메뉴얼

> **대상**: MSYS(수집 현황 대시보드) 시스템 운영자 · 인수인계자 · 관리자(admin)
> **목적**: 시스템 운영에 필요한 메뉴별 조작 절차, 모니터링, 장애 대응을 한곳에서 안내
> **구성**: 본 진입점(목록) + 메뉴별 파일 + 부록. 각 메뉴 파일은 하단의 "이전/다음" 링크로 이동 가능.
