## 조작 절차

### 1. 아이콘 등록/수정

**목적:** 시스템에서 사용할 아이콘을 관리합니다.

**조작 절차:**
1. 아이콘 탭 선택
2. 등록 버튼 클릭
3. 아이콘 코드, 이름, 설명 입력
4. 이미지 업로드
5. 저장 버튼 클릭

### 2. 아이콘 가져오기/내보내기

**조작 절차:**
- 내보내기: CSV 버튼 클릭 → `icons.csv` 다운로드
- 가져오기: 파일 선택 → CSV 업로드 → 확인
