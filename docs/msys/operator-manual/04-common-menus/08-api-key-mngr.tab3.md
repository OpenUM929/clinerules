# API 키 관리 — 위험군 탭

## 정의

1개월 이내로 만료되는 API 키

**메일 전송 상태 필터:**
| 필터 | 설명 |
|------|------|
| 전체 | 모든 위험군 키 |
| ✅ 전송완료 | 알림 메일이 성공적으로 전송된 키 |
| ❌ 전송실패 | 알림 메일 전송에 실패한 키 |
| ⏳ 대기중 | 아직 알림 메일이 전송되지 않은 키 |
