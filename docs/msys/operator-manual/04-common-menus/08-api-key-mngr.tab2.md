## 간트 차트 (Gantt Chart)

- 각 API 키의 유효기간을 막대 그래프로 시각화
- X축: 시간 (등록일 ~ 만료일)
- Y축: API 키 코드명
- 오늘 날짜 기준 빨간색 세로선 표시
- 상태별 막대 색상: 녹색(정상), 주황(만료임박), 빨강(오버)
- 마우스 오버 시 툴팁으로 상세 정보 표시
