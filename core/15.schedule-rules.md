# 15. Schedule Rules (스케줄 규칙)

> ⚠️ **이 문서는 에밀리 프로젝트의 스케줄 시스템 규칙을 정의합니다.**

---

## 1. 아키텍처 개요

### 1.1 시스템 구조

```
주간 계획 (Weekly Plan)
├── 데이터 저장소: 각 요일별 AM/PM 활동 정의
├── 상태 표시: 실행된 활동은 ✓ + 비활성화 + 옅은 회색
└── 14개 슬롯: 월(AM,PM) ~ 일(AM,PM)

스케줄 (Schedule)
├── 오늘의 실행 뷰: 오늘 날짜의 활동만 표시
├── 실행 버튼: 오늘의 활동만 실행 가능
└── 주간계획 추가: 주간 계획에 활동 추가 가능
```

### 1.2 핵심 변수

| 변수 | 타입 | 설명 | 범위 |
|------|------|------|------|
| `currentSlotIndex` | number | 현재 슬롯 위치 | 1~14 |
| `weekNumber` | number | 주차 카운터 | 1~∞ |

### 1.3 슬롯 인덱스 매핑

| 인덱스 | 요일 | 시간대 | 계산 공식 |
|--------|------|--------|-----------|
| 1 | 월 | AM | - |
| 2 | 월 | PM | - |
| 3 | 화 | AM | - |
| 4 | 화 | PM | - |
| 5 | 수 | AM | - |
| 6 | 수 | PM | - |
| 7 | 목 | AM | - |
| 8 | 목 | PM | - |
| 9 | 금 | AM | - |
| 10 | 금 | PM | - |
| 11 | 토 | AM | - |
| 12 | 토 | PM | - |
| 13 | 일 | AM | - |
| 14 | 일 | PM | - |

## 2. 실행 규칙

### 2.1 실행 순서 (Execution Order)

```
1(월AM) → 2(월PM) → 3(화AM) → 4(화PM) → ... → 13(일AM) → 14(일PM)
```

### 2.2 핵심 규칙

| # | 규칙 | 설명 |
|---|------|------|
| 1 | **오늘만 실행** | 스케줄에서 오늘 날짜의 활동만 실행 가능 |
| 2 | **AM → PM 순서** | 오늘 AM 실행 후 PM 실행 가능 |
| 3 | **자동 전환** | 오늘 AM+PM 완료 시 자동으로 다음 날로 전환 |
| 4 | **실행 = 상태 업데이트** | 활동 실행 시 주간 계획에 ✓ 표시 |
| 5 | **주간계획 추가** | 스케줄에서 주간 계획에 활동 추가 가능 |
| 6 | **자동 날짜 추적** | 현재 날짜는 자동으로 추적 (수동 선택 없음) |

### 2.3 실행 불가 조건

| 상황 | 결과 |
|------|------|
| 오늘 AM이 실행되지 않았음 | 오늘 PM 실행 불가 |
| 오늘 AM+PM이 모두 실행되었음 | 자동으로 다음 날로 전환 |
| 슬롯이 비어있음 | 해당 슬롯 실행 불가 (건너뜀) |

### 2.4 실행 예시

**예시1: 월~수 오전까지 스케줄 존재**

| 요일 | AM | PM |
|------|----|----|
| 월 | ✅ 있음 | ✅ 있음 |
| 화 | ✅ 있음 | ✅ 있음 |
| 수 | ✅ 있음 | ❌ 없음 |
| 목 | ❌ 없음 | ❌ 없음 |

실행 흐름:
1. 현재 위치: 1(월 AM) → 실행 → 2(월 PM)로 이동
2. 현재 위치: 2(월 PM) → 실행 → 3(화 AM)로 이동
3. 현재 위치: 3(화 AM) → 실행 → 4(화 PM)로 이동
4. 현재 위치: 4(화 PM) → 실행 → 5(수 AM)로 이동
5. 현재 위치: 5(수 AM) → 실행 → 6(수 PM)으로 이동
6. 현재 위치: 6(수 PM) → 비어있음 → 건너뜀 → 7(목 AM)으로 이동
7. 현재 위치: 7(목 AM) → 비어있음 → 건너뜀 → ...

**실행 결과**: 5개 슬롯 실행 (월 AM, 월 PM, 화 AM, 화 PM, 수 AM)

## 3. UI 구성 규칙

### 3.1 스케줄 섹션 (오늘의 실행 뷰)

```
┌─────────────────────────────────────────┐
│ 1주차 - 1일차 (월 AM)                    │
│ 진행률: ████████░░░░░░░░░░░░ 7%          │
├─────────────────────────────────────────┤
│ 오늘: 월요일                            │
│                                         │
│ [오전]                                   │
│ 활동: 산책                               │
│ 버튼: [실행] → 실행后 [실행완료] (비활성화)│
│                                         │
│ [오후]                                   │
│ 활동: 독서                               │
│ 버튼: [실행] → 대기                      │
│                                         │
│ [주간계획 추가] 버튼                      │
└─────────────────────────────────────────┘
```

### 3.2 주간 계획 테이블 (상태 표시)

| 요일 | 오전 (AM) | 오후 (PM) |
|------|-----------|-----------|
| 월 | 산책 ✓ | 독서 |
| 화 | 요가 | 운동 |
| 수 | 독서 | - |

**실행된 활동 스타일**:
- ✓ 아이콘 표시
- 비활성화 (opacity-50)
- 옅은 회색 배경

### 3.3 슬롯 상태

| 상태 | 표시 | 비활성화 | 배경 |
|------|------|----------|------|
| **비어있음** | "없음" | - | - |
| **채워짐 (미실행)** | 활동 이름 | - | - |
| **실행 완료** | 활동 이름 ✓ | Yes | 옅은 회색 |

### 3.4 활동 카드

| 버튼 | 기능 | 비고 |
|------|------|------|
| `[주간계획 추가]` | 주간 계획에 활동 추가 | 현재 탭(AM/PM)의 첫 빈 슬롯에 추가 |
| `[실행]` | 오늘의 활동 실행 | 오늘 날짜의 해당 슬롯만 실행 |

### 3.5 초기화 버튼

| 버튼 | 기능 |
|------|------|
| `[주간 초기화]` | 모든 슬롯 초기화 |
| `[오전 초기화]` | AM 슬롯만 초기화 |
| `[오후 초기화]` | PM 슬롯만 초기화 |

## 4. 구현 상세

### 4.1 데이터 구조

```typescript
// 슬롯 상태 인터페이스
interface SlotState {
  activityId: string;
  executed: boolean;
}

// 주간 계획 상태
const [weekly, setWeekly] = useState<Record<string, { am: SlotState | null; pm: SlotState | null }>>(
  Object.fromEntries(DAYS.map((d) => [d, { am: null, pm: null }]))
);

// 현재 위치 추적
const [currentSlotIndex, setCurrentSlotIndex] = useState<number>(1); // 1~14
const [weekNumber, setWeekNumber] = useState<number>(1);            // 주차 카운터
```

### 4.2 변환 함수

```typescript
// 인덱스 → 요일+시간대 변환
const indexToSlot = (index: number) => {
  const dayIndex = Math.floor((index - 1) / 2);  // 0~6
  const period = index % 2 === 1 ? "am" : "pm";   // 홀수=AM, 짝수=PM
  return { day: DAYS[dayIndex], period };
};

// 요일+시간대 → 인덱스 변환
const slotToIndex = (day: string, period: string) => {
  const dayIndex = DAYS.indexOf(day);  // 0~6
  const periodOffset = period === "am" ? 0 : 1;
  return dayIndex * 2 + periodOffset + 1;
};
```

### 4.3 핵심 함수

| 함수 | 설명 |
|------|------|
| `addToWeekly(activityId)` | 활동을 주간 계획에 추가 |
| `runSingle(activityId)` | 오늘의 활동 실행 |
| `moveToNextSlot()` | 다음 슬롯으로 이동 |
| `resetWeeklyAll()` | 모든 슬롯 초기화 |
| `resetWeeklyAm()` | AM 슬롯만 초기화 |
| `resetWeeklyPm()` | PM 슬롯만 초기화 |

### 4.4 실행 흐름

1. 사용자가 스케줄에서 `[실행]` 버튼 클릭
2. `runSingle(activityId)` 호출
3. 오늘의 슬롯 실행 → `weekly[day][period].executed = true`
4. `moveToNextSlot()` 호출 → 다음 슬롯으로 이동
5. 14개 슬롯 모두 실행 완료 시 `currentSlotIndex > 14`
6. 자동으로 다음 주로 전환 (`weekNumber++`, `currentSlotIndex = 1`)

## 6. 주의 사항

1. **실행 버튼 위치**: 스케줄 섹션에만 존재 (주간 계획 테이블에 실행 버튼 없음)
2. **AM → PM 순서**: 반드시 AM 먼저 실행 후 PM 실행
3. **슬롯 비활성화**: 실행 완료된 슬롯은 ✓ + 비활성화 + 옅은 회색
4. **자동 전환**: 오늘 AM+PM 완료 시 자동으로 다음 날로 전환
5. **부분 실행**: 채워진 슬롯만 실행, 빈 슬롯은 건너뜀
6. **자동 날짜 추적**: 현재 날짜는 자동으로 추적 (수동 선택 없음)
