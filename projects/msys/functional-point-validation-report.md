## 1️⃣ 기능유형 분류 검증

### 1.1 EI (External Input - 4.0 FP) 검증

#### ✅ 적절한 EI 사례

```
✓ 로그인/로그아웃 → ID/PW 입력 → 세션 생성 (ILF 변경)
✓ 비밀번호 변경 → 신규 비밀번호 입력 → tb_user 변경
✓ 명세서 등록 → URL 입력 → tb_data_spec 저장
✓ API 키 관리 → 키/만료일 입력 → tb_api_key_mngr 변경
✓ 사용자 권한 설정 → 권한 선택 → tb_user_auth_ctrl 변경
✓ 팝업 관리 → 제목/내용/이미지 입력 → tb_popup_mst 변경
✓ 컬럼 매핑 → 필드 매핑 규칙 입력 → tb_col_mapp 변경
```

**판정**: ✅ **타당**  
모두 사용자 입력 → ILF 변경 구조

#### ⚠️ 주의사항: 공통 모듈 중복 제거

**계획서 식별**
```
§2.4 "중복/공통 함수 (FP 중복 카운트 배제 → 공통 모듈 1회 산정)"
- 인증 공통 (로그인/로그아웃/비밀번호변경) → auth_routes.py (1회만)
- 권한/메뉴 관리 공통 (*_required 데코레이터 11개) → 관리자설정에서만
- 메뉴 접속로그 (log_menu_access) → 첫 사용 메뉴에서만
- 엑셀 업/다운로드 → 통계에서만
- 공통 조회 → routes/api/__init__.py (1회만)
- 팝업 관리 → popup_routes.py (1회만)
- 사용자접속통계 (2중 구현) → 통합 필요

```
