# A4 보고서 작성 통합 지침 (md_editor)

> 🔴 **이 문서는 운영자 메뉴얼 작성의 최우선 정본이다(모든 프로젝트 매뉴얼 공용).**
> **양식·페이지 구성·마크업(이미지·페이지나눔·표·개조식)에서 `DEVELOPMENT/` 다른 원자 문서(01~08)와 충돌하면 무조건 이 문서를 따른다.**
> 나침반 [../DEVELOPMENT.md](../../DEVELOPMENT.md) · 이 문서의 **마크업 위생 규칙**(표준 md만·`![]()`·`---pb---`·인라인 `<style>`/`<div>`/`<img width>` 금지)은 **렌더러와 무관하게 항상 유효**하다.
>
> 🟢 **시각 양식(form)의 정본은 렌더 경로에 따라 다르다(2026-07-23):**
> - **이 리포의 운영자·개발 메뉴얼** → 정본 렌더·양식 = **`print.css` 통합빌드**([06-integrated-build.md](../06-integrated-build.md)). 대제목 밑줄 경계선·표·인용문 바 등 "보이는 양식"은 `print.css`가 그린다. 프론트매터 `reportTheme:` 는 이 경로에서 **무시**되는 선택적 메타데이터다.
> - **외부 md_editor(Tiptap) 도구로 편집·출력하는 문서** → 아래 §1~§8의 `reportTheme` 양식이 적용된다(테마 CSS `report-theme.css`는 외부 md_editor 저장소 기준). 이 경우 대제목은 회색 박스 등 테마별 양식을 따른다.
>
> 아래 본문은 md_editor(Tiptap) 도구 기준으로 작성된 원문이다. 이 리포 매뉴얼을 print.css로 빌드할 때의 양식 사양은 **[06-integrated-build.md §3](../06-integrated-build.md)** 가 정본이다.

## 0. 핵심 원칙 (이 5줄이 전부다)

1. **한 페이지 = 하나의 완결된 주제.** 섹션(`##`)이 페이지 하단에서 시작해 다음 장으로 새지 않는다.
2. **페이지 나눔은 작성자가 `---pb---`로 명시**한다. 자동 나눔에 맡기지 않는다(§4에서 이유 확정).
3. **한 블록 ≤ 한 페이지** (인쇄 가능 높이 기본 257mm). 넘치는 표는 헤더 반복 분할, 큰 이미지는 단독 페이지.
4. **표준 마크다운만 사용.** 인라인 `<style>`·rp_gen 전용 HTML·픽셀 폭 이미지는 떨궈지거나 넘친다.
5. **양식은 프론트매터 `reportTheme`로 지정.** CSS가 그리고, 수정은 Tiptap이 그 자리에서 담당한다.
