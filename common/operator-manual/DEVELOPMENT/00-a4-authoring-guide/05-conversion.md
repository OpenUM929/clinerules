# 변환 절차 (기존 rp_gen 문서 → md_editor)

> 상위 나침반 [`../00-a4-authoring-guide.md`](../00-a4-authoring-guide.md) 에서 분리.

## 5. 변환 절차 (기존 rp_gen 문서 → md_editor)

### 5-1. 전역 치환 (문서 전체 일괄) — §2-4 치환표대로
1. 상단 `<style>` 삭제 → 프론트매터 `reportTheme: report`.
2. `<div class="pagebreak">` → `---pb---` (단, **주제 경계로 재배치** — 원본 위치 그대로가 아니라 §4-3 밀도 반영).
3. `<div align="right">` → `**작성자**` 일반 라인.
4. `<div class="headline">` → 첫 `>` 인용.
5. `<table class="kpi">` → 표준 4열 표.
6. `<span class="att">붙임N</span> **제목**` → `**[붙임N] 제목**`.
7. `<p class="cap">` → `> ※ …`.
8. `<img width="…">` → `![]()` (폭 제거, 파일 존재 확인).

### 5-2. `□`/`○` → 마크다운 목록 (§3-5)
`□ 내용` → `- 내용`, 중첩 `○` → `  - 내용`. 테마가 마커를 그린다.

### 5-3. 긴 표 분할 (§3-2) / 큰 이미지 단독 페이지 (§3-3)

### 5-4. 원본 보존
변환 전 원본을 **백업**한다(`*.style-backup.md` 등). 저장소가 git이 아니면 특히 필수. 원본 파일 덮어쓰기는 사용자 확인 후.

### 5-5. 실측 미세조정 (필수)
높이 추정은 이미지 크기·폰트 렌더로 ±1장 흔들린다. **분리 모드 스크린샷으로 페이지별 주제 완결·넘침·공백을 보고 `---pb---` 위치를 2회 내외 조정**해 확정한다.
