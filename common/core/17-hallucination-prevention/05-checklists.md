# 작업별 체크리스트

> 상위 나침반 [`../17-hallucination-prevention.md`](../17-hallucination-prevention.md) 에서 분리.

## 4️⃣ 작업별 체크리스트

### 비교분석 보고서 작성 시

```
□ 계획서 전체를 Read 도구로 읽었는가?
□ 최종 보고서 전체를 Read 도구로 읽었는가?
□ 두 문서가 같은 프로젝트인지 확인했는가?
□ 섹션별 대응 관계를 표로 정리했는가?
□ "신규 추가" 표기한 항목을 계획서에서 찾아봤는가?
□ 찾을 수 없는 항목은 삭제했는가?
□ 불확실한 항목은 "미확인" 또는 "검증 필요" 표기했는가?
□ 각 항목마다 출처(페이지/섹션)를 명시했는가?
□ 최종 검수: 문서 다시 한번 읽어서 거짓 정보가 없는가?
```

### 영향도 분석 작성 시

```
□ 수정 대상 파일을 직접 읽었는가?
□ 참조하는 파일들을 모두 Grep/Read로 확인했는가?
□ "영향을 줄 수 있다"고 표기한 파일들을 실제로 검사했는가?
□ 추측이 아닌 실제 코드 기반으로만 작성했는가?
```

### 기능 설명/현황 분석 시

```
□ 실제 코드/문서를 읽었는가?
□ 스크린샷이나 메모리만 믿지 않았는가?
□ "~하는 것 같다"는 추측을 피했는가?
□ 불확실한 부분은 사용자에게 확인했는가?
```
