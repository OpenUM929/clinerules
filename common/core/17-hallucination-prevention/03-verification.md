# 검증 프로세스

> 상위 나침반 [`../17-hallucination-prevention.md`](../17-hallucination-prevention.md) 에서 분리.

## 2️⃣ 검증 프로세스 (비교/영향도/분석 작업 시)

### 단계별 체크리스트

#### 📋 Step 1: 사전 검증 (작업 시작 전)
- [ ] 요청이 "비교", "분석", "영향도" 등의 키워드를 포함하는가?
- [ ] 필요한 원본 문서가 존재하는가? (없으면 사용자에게 확인)
- [ ] 문서 규모가 너무 크지는 않은가? (너무 크면 Read 도구의 limit/offset 사용)

#### 📋 Step 2: 원본 읽기 (Read 도구 필수)
```
계획서/기존문서 읽기 → 최종문서/현행문서 읽기 → 구조/내용 파악
```

- [ ] 두 문서의 구조를 파악했는가?
- [ ] 섹션/항목 대응 관계를 파악했는가?
- [ ] 불일치하는 부분을 찾았는가?

#### 📋 Step 3: 실제 차이점만 추출
```
계획서 항목 ←→ 최종 보고서에서 찾기 ← YES or NO?
```

- [ ] "신규 추가" 항목들이 정말 계획서에 없는가?
- [ ] "강화된" 항목들이 정말 더 상세해졌는가?
- [ ] "생성된" 항목들이 실제로 존재하는가?

#### 📋 Step 4: 거짓 항목 삭제
- [ ] 원본에서 찾을 수 없는 항목은 모두 삭제했는가?
- [ ] 불확실한 항목은 "미확인" 표기했는가?
