# 「데이터가 없다」 단정 금지

> 최종 개정 2026-08-20 (당일 제1차) — rev-260820-01
>
> 상위 나침반 [`../17-hallucination-prevention.md`](../17-hallucination-prevention.md) 에서 분리.
> **없는 것을 있다고 말하는 것만 환각이 아니다. 있는 것을 없다고 말하는 것도 환각이다.**
> ABS-1~8 은 **부재를 성급히 단정하지 않기 위한** 확인 절차이고, ABS-9~10 은 **부재가 확정된 뒤** 그 근거 위에 서 있던 수치를 어떻게 처리하는지다(같은 확정 절차를 쓴다).

---

## 왜 이 문서가 생겼나 — 실제 사고

2026-07-27~28, 완료 보고서 작성 중 **같은 오판을 3회 반복**했다.

| 회차 | 내가 한 말 | 실제 |
|------|-----------|------|
| 1 | "해당 구분 라벨이 자료에 남아 있지 않다" | 파생 export 1개에만 없었다. 다른 export 에는 레코드 `id` 접두사로 살아 있었다 |
| 2 | "재배치가 이 파일을 **입력**으로 썼다" | 그 파일은 파이프라인의 **출력**이었다. 헤더 첫 줄에 생산 배치 ID 가 찍혀 있었다 |
| 3 | "라벨이 비어 있어 대사할 수 없다" | 사용자가 파일 **위치까지 지정해 3회 알려준 뒤**였다 |

**근본 원인**: 값을 어디서 얻는지 이미 알고 있는 코드(내가 직전에 작성한 측정 스크립트)를 **읽지 않았다.** 답은 그 스크립트의 `field_of()` 함수 3줄에 있었다.

**피해**: 대외 제출 보고서에 사실과 다른 한계 고지가 실릴 뻔했고, 사용자 신뢰를 잃었으며, 같은 작업을 4회 반복했다.

---

## ABS-1. 부재 주장은 **전 경로 확인 후에만**

어떤 값이 "없다"고 쓰거나 말하기 전에, 그 값이 존재할 수 있는 **모든 경로를 열거하고 각각 확인**한다.

| 확인 경로 | 방법 |
|-----------|------|
| ① 명시 필드 | 해당 키를 직접 조회 |
| ② 식별자 내부 | `id`·파일명·경로에 인코딩돼 있는지 (접두사·접미사·구분자) |
| ③ 배치/그룹 단위 | 파일 단위·배치 단위로 분리돼 값이 **파일명·배치ID로 대체**돼 있는지 |
| ④ 순서·구조 | 레코드 순서·부모자식 관계가 값을 담고 있는지 |
| ⑤ 상위 원본 | 파생본이 아닌 **원본 DB·원천 파일** |
| ⑥ 형상관리 이력 | 작업 트리에 없어도 이력에 남아 있는지 — 해당 경로의 **추가·삭제 커밋을 조회**(파일시스템 조회만으로 소실을 확정하지 않는다) |

**①에서 0건이 나왔다는 것은 ①에 없다는 뜻일 뿐이다.** ②~⑥을 확인하지 않은 상태에서 "자료에 없다"고 쓰는 것은 금지한다.

> 파생본에 없다 ≠ 원본에 없다.

## ABS-2. 파일의 **입력/출력 방향**을 먼저 확정한다

파일을 근거로 인용하기 전에 그 파일이 파이프라인의 **입력인지 출력인지** 확정한다.

1. 파일 **첫 줄(헤더·메타행)** 을 읽는다 — 생산 도구·배치 ID·스키마 설명이 여기 있는 경우가 많다.
2. 그 파일을 **생산하는 코드**를 찾아 읽는다(Grep 으로 파일명·확장자 검색).
3. 확정되기 전에는 "원천 데이터", "입력 데이터"라고 부르지 않는다.

방향을 틀리면 **인과가 통째로 뒤집힌 진단**이 나온다.

## ABS-3. **내가 쓴 코드부터 읽는다**

"이 값을 어떻게 얻지?" 라는 질문이 생기면, 새 조사를 시작하기 전에 **같은 값을 이미 다루는 코드가 있는지 먼저 찾는다.**

- 산출물 폴더(`result/`, `scripts/`)의 **기존 측정 스크립트**
- 그 스크립트가 값을 **어떤 경로로 얻는지**(파싱 함수·매핑 상수)

세션 앞부분에서 내가 직접 만든 스크립트도 예외가 아니다. **기억이 아니라 파일을 읽는다.**

## ABS-4. 사용자가 **같은 지적을 2회** 하면 결론을 폐기한다

같은 사실에 대해 사용자가 두 번째로 정정하면, 내 결론은 **부분 수정 대상이 아니라 폐기 대상**이다.

1. 기존 결론과 그 근거를 **전부 버린다**.
2. 사용자가 제시한 위치·파일을 **직접 연다**(추론으로 대체 금지).
3. 처음부터 다시 조사한다.

기존 결론을 유지한 채 문구만 다듬는 것은 3회차 반복을 만든다.

## ABS-5. 가설은 **전수 검정 후** 채택한다

몇 줄을 눈으로 보고 규칙성을 발견했다면 그것은 **가설**이다. 결론으로 쓰기 전에 전수로 검정한다.

| 단계 | 내용 |
|------|------|
| 1 | 가설을 반증 가능한 형태로 적는다 (예: "홀수 순번 = B그룹") |
| 2 | 전체 데이터에 적용해 **분포를 낸다** |
| 3 | 무작위 수준(50:50 등)이면 **기각하고 그렇게 기록한다** |

기각한 가설도 문서에 남긴다. 남기지 않으면 다음 세션이 같은 가설을 다시 세운다.

## ABS-6. 부분집합 수치에는 **모집단과 추출 조건**을 병기한다

부분집합에서 낸 값을 전체 대표치처럼 쓰지 않는다.

- 항상 병기: **모집단 규모 · 부분집합 규모 · 커버리지(%) · 추출 조건**
- 추출 조건이 결과 지표와 **상관**되면(예: 어려운 것만 모은 집합, 반복 상용구만 모인 집합) 그 방향과 크기를 명시한다
- 보정이 가능하면 **같은 절차를 전수 확정된 다른 표본에 재현해 편향계수를 실측**한다. 추측 보정 금지

## ABS-7. **이미 측정한 값**을 먼저 소진한다

새로 측정하기 전에, 그리고 "미측정"이라고 쓰기 전에 산출물 폴더의 기존 결과 파일을 조회한다. 상세 문서에 있는 수치가 요약 문서에 빠지는 일이 반복됐다.

- 요약본 작성 시 **상세본에 있는 수치가 전부 반영됐는지 대조**한다
- 연도·구분별 자료가 여러 개면 **일부만 싣지 않는다**. 못 실으면 사유를 쓴다

## ABS-8. 총량을 표본으로 축소해 쓰지 않는다

- 사람 확정분·검증분 등은 **총량을 먼저 쓰고**, 그중 특정 목적에 쓴 표본은 **용도를 명시해 따로** 쓴다
- 표본 수만 단독 인용하면 실제 규모를 수십 배 축소해 **신뢰도를 스스로 깎는다**

## ABS-9. **재현 불가가 확정된 수치**는 한계 고지가 아니라 근거에서 제외한다

수치의 근거(원자료·판독 원본·산출 스크립트·시드)가 소실돼 **누가 다시 해도 같은 값을 낼 수 없음**이 확인되면, 그 수치는 **한계 문서에 적어 두는 대상이 아니라 근거 목록에서 빼는 대상**이다. 적어 두는 것과 쓰지 않는 것은 다르다.

> **실사고** — 대외 제출 결과보고서 세트에서 실배치 감사 수치 1종이 다른 두 측정과 나란히 「세 측정이 수렴한다」는 성능 근거로 실려 있었다. 그러나 그 값의 표본 판독 원본은 파일시스템에도 형상관리 이력에도 없었다(추가·삭제 기록 0건). 소실 사실은 같은 세트의 한계 문서에 정확히 적혀 있었으나, 결과 문서에서는 그 값이 계속 근거였다.

| 단계 | 내용 |
|------|------|
| ① 소실 확정 | ABS-1 ①~⑥ 을 전부 확인한다. **⑥ 형상관리 이력까지** 조회해 추가·삭제 기록이 0건임을 실측한 뒤에만 「소실」이라고 쓴다 |
| ② 인용 금지 표기 | 그 수치를 산출·설명하는 문서에 **「철회된 측정 — 인용 금지」** 를 1회 명시하고, 사유와 확인 방법을 함께 적는다 |
| ③ 근거에서 제외 | 성능·품질 주장의 **근거 목록에서 뺀다.** 남은 근거만으로 주장이 서지 않으면 **주장을 그만큼 낮춘다** |
| ④ 인용처 동시 정정 | Grep 으로 **전 인용처**를 찾아 같은 개정에서 전부 고친다. 한 문서에만 적고 끝내지 않는다 |
| ⑤ 이력 보존 | 철회 사실·사유는 **개정 이력 절 1개**에만 남긴다([16-report-writing.md](../16-report-writing.md) §2-10) |

여러 측정의 **수렴**을 보이는 근거로 쓰였다면, 하나가 빠진 뒤의 수렴 문장도 다시 쓴다. 값만 지우고 결론 문장을 그대로 두지 않는다.

## ABS-10. 표본 재현 ≠ 값 재현

| 남아 있는 것 | 판정 |
|---|---|
| 추출 스크립트 + 시드 + 원천 데이터 | **표본만 재현.** 값은 재현 아님 |
| 표본 + 판정 결과(라벨·판독 원본) | 재현 가능 — 집계를 다시 돌리면 같은 값 |
| 집계 요약본(표·%)만 | 재현 아님 — 요약은 근거가 아니라 결과다 |

같은 표본을 다시 뽑을 수 있다는 것은 **입력을 복원할 수 있다**는 뜻일 뿐, 그때 사람이 내린 판정은 복원되지 않는다. 다시 판정하면 그것은 **새 측정**이므로 값·일자·절차를 새로 적고, 기존 값은 ABS-9 로 처리한다.

## 체크리스트 — 「없다」라고 쓰기 직전

- [ ] ABS-1 의 ①~⑥ 을 **전부** 확인했는가(⑥ 형상관리 이력 포함)
- [ ] 근거 파일이 입력인지 출력인지 **헤더·생산코드로** 확정했는가
- [ ] 같은 값을 다루는 **기존 코드**를 찾아 읽었는가
- [ ] 사용자가 알려준 위치를 **직접 열어** 봤는가
- [ ] 규칙성 주장은 **전수 분포**로 검정했는가
- [ ] 부분집합이면 모집단·커버리지·편향 방향을 적었는가
- [ ] 확인 못 한 경로가 남았다면 "없다"가 아니라 **"어디까지 확인했고 무엇이 남았다"** 로 썼는가
- [ ] 소실이 확정된 값을 **근거 목록에 남겨 두지** 않았는가 — 인용 금지 표기 + 전 인용처 동시 정정까지 마쳤는가 (ABS-9)
- [ ] 「재현 가능」이라 쓴 값에 **판정 결과 원본**이 남아 있는가 — 표본만 다시 뽑을 수 있는 상태를 재현이라 부르지 않았는가 (ABS-10)

> 하나라도 미확인이면 결론은 **"미확인"** 이지 **"없음"** 이 아니다.
> 그리고 **소실이 확정된 근거 위의 수치는 "한계"가 아니라 "제외"** 다.
