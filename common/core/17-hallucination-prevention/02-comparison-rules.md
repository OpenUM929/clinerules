# 비교분석 작성 규칙

> 상위 나침반 [`../17-hallucination-prevention.md`](../17-hallucination-prevention.md) 에서 분리.

## 1️⃣ 비교분석 작성 규칙

### 규칙: 원본 검증 의무화

**금지 행위**
- ❌ 계획서/보고서를 읽지 않고 "신규 추가", "강화된" 등으로 표기
- ❌ 특정 항목이 "있을 것 같아서" 마치 있는 것처럼 작성
- ❌ 기억 또는 일반적 상식을 기반으로 비교 내용 생성

**필수 절차**

1. **양쪽 원본 모두 읽기**
   - 계획서 전체 읽기 (Read 도구)
   - 최종 보고서 전체 읽기 (Read 도구)
   - 같은 프로젝트인지 확인 (프로젝트명, 개발기간, FP 등)

2. **실제 차이점만 기록**
   - "계획서에는 X가 없고, 보고서에는 Y가 있다" 형태로만 작성
   - 각 항목마다 출처 명시 (페이지/섹션)
   - 불확실한 항목은 "미확인" 표기

3. **거짓 항목 즉시 제거**
   - 원본에서 찾을 수 없는 항목 발견 시 삭제
   - "신규 추가"라고 표기했던 항목이 실제로는 없으면 수정/삭제

### 예시: 정확한 비교

```
❌ 거짓 (환각):
"최종 보고서에는 '사용자 만족도 4.5/5.0'이 신규 추가되었습니다."
→ 계획서를 읽지 않고 작성 (계획서에는 만족도 항목 자체가 없음)

✅ 정확함:
"계획서 p.1에는 없고, 최종 보고서 p.690(5.4절)에만 
'사용자 만족도 4.5/5.0, 교육참석 15명 100%' 항목이 있습니다."
→ 양쪽 모두 읽고 검증한 후 작성
```
