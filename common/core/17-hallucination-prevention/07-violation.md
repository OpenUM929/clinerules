# 위반 시 처리

> 상위 나침반 [`../17-hallucination-prevention.md`](../17-hallucination-prevention.md) 에서 분리.

## 6️⃣ 위반 시 처리

### 환각 발견 즉시 조치

1. **작업 중단**
   - 현재 진행 중인 작업 멈춤

2. **원인 분석**
   - 어디서 환각이 발생했는가?
   - 왜 검증을 건너뛰었는가?

3. **수정 및 재작성**
   - 거짓 정보 삭제
   - 원본을 다시 읽어서 정확한 내용으로 재작성
   - 사용자에게 수정 사항 보고

4. **예방**
   - 이전 환각과 유사한 패턴 앞으로 주의

### 사용자 지적 시

- ✅ 즉시 인정 ("제가 환각으로 작성했습니다")
- ✅ 원본 다시 읽기
- ✅ 거짓 항목 제거
- ✅ 정확한 버전 재작성
- ✅ 같은 실수 반복 방지
