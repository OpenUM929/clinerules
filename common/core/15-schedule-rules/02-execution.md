# 실행 규칙

> 상위 나침반 [`../15-schedule-rules.md`](../15-schedule-rules.md) 에서 분리.

## 2. 실행 규칙

### 2.1 실행 순서 (Execution Order)

```
1(월AM) → 2(월PM) → 3(화AM) → 4(화PM) → ... → 13(일AM) → 14(일PM)
```

### 2.2 핵심 규칙

| # | 규칙 | 설명 |
|---|------|------|
| 1 | **오늘만 실행** | 스케줄에서 오늘 날짜의 활동만 실행 가능 |
| 2 | **AM → PM 순서** | 오늘 AM 실행 후 PM 실행 가능 |
| 3 | **자동 전환** | 오늘 AM+PM 완료 시 자동으로 다음 날로 전환 |
| 4 | **실행 = 상태 업데이트** | 활동 실행 시 주간 계획에 ✓ 표시 |
| 5 | **주간계획 추가** | 스케줄에서 주간 계획에 활동 추가 가능 |
| 6 | **자동 날짜 추적** | 현재 날짜는 자동으로 추적 (수동 선택 없음) |

### 2.3 실행 불가 조건

| 상황 | 결과 |
|------|------|
| 오늘 AM이 실행되지 않았음 | 오늘 PM 실행 불가 |
| 오늘 AM+PM이 모두 실행되었음 | 자동으로 다음 날로 전환 |
| 슬롯이 비어있음 | 해당 슬롯 실행 불가 (건너뜀) |

### 2.4 실행 예시

**예시1: 월~수 오전까지 스케줄 존재**

| 요일 | AM | PM |
|------|----|----|
| 월 | ✅ 있음 | ✅ 있음 |
| 화 | ✅ 있음 | ✅ 있음 |
| 수 | ✅ 있음 | ❌ 없음 |
| 목 | ❌ 없음 | ❌ 없음 |

실행 흐름:
1. 현재 위치: 1(월 AM) → 실행 → 2(월 PM)로 이동
2. 현재 위치: 2(월 PM) → 실행 → 3(화 AM)로 이동
3. 현재 위치: 3(화 AM) → 실행 → 4(화 PM)로 이동
4. 현재 위치: 4(화 PM) → 실행 → 5(수 AM)로 이동
5. 현재 위치: 5(수 AM) → 실행 → 6(수 PM)으로 이동
6. 현재 위치: 6(수 PM) → 비어있음 → 건너뜀 → 7(목 AM)으로 이동
7. 현재 위치: 7(목 AM) → 비어있음 → 건너뜀 → ...

**실행 결과**: 5개 슬롯 실행 (월 AM, 월 PM, 화 AM, 화 PM, 수 AM)
