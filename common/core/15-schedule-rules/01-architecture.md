# 아키텍처 개요

> 상위 나침반 [`../15-schedule-rules.md`](../15-schedule-rules.md) 에서 분리.

## 1. 아키텍처 개요

### 1.1 시스템 구조

```
주간 계획 (Weekly Plan)
├── 데이터 저장소: 각 요일별 AM/PM 활동 정의
├── 상태 표시: 실행된 활동은 ✓ + 비활성화 + 옅은 회색
└── 14개 슬롯: 월(AM,PM) ~ 일(AM,PM)

스케줄 (Schedule)
├── 오늘의 실행 뷰: 오늘 날짜의 활동만 표시
├── 실행 버튼: 오늘의 활동만 실행 가능
└── 주간계획 추가: 주간 계획에 활동 추가 가능
```

### 1.2 핵심 변수

| 변수 | 타입 | 설명 | 범위 |
|------|------|------|------|
| `currentSlotIndex` | number | 현재 슬롯 위치 | 1~14 |
| `weekNumber` | number | 주차 카운터 | 1~∞ |
