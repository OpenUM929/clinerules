# 테스트 규칙

> 상위 나침반 [`../15-schedule-rules.md`](../15-schedule-rules.md) 에서 분리.

## 5. 테스트 규칙

### 5.1 테스트 시나리오

| 시나리오 | 설명 |
|----------|------|
| 오늘의 활동 표시 | 스케줄에 오늘 날짜의 활동만 표시되는지 확인 |
| AM 실행 후 PM 실행 | 오늘 AM 실행 후 PM 실행 버튼이 활성화되는지 확인 |
| 자동 전환 | 오늘 AM+PM 완료 시 자동으로 다음 날로 전환되는지 확인 |
| 실행 상태 표시 | 실행된 활동은 ✓ + 비활성화 + 옅은 회색으로 표시되는지 확인 |
| 주간계획 추가 | 스케줄에서 주간 계획에 활동 추가 가능한지 확인 |
| 1주 완료 시 전환 | 14개 슬롯 모두 완료 시 자동으로 다음 주로 전환되는지 확인 |

### 5.2 테스트 파일 위치

```
tests/
├── schedule-weekly-add.spec.ts      # 주간계획 추가 테스트

├── schedule-weekly-reset.spec.ts    # 초기화 테스트
└── schedule-execution.spec.ts       # 실행 규칙 테스트
```
