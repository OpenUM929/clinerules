# UI 구성 규칙

> 상위 나침반 [`../15-schedule-rules.md`](../15-schedule-rules.md) 에서 분리.

## 3. UI 구성 규칙

### 3.1 스케줄 섹션 (오늘의 실행 뷰)

```
┌─────────────────────────────────────────┐
│ 1주차 - 1일차 (월 AM)                    │
│ 진행률: ████████░░░░░░░░░░░░ 7%          │
├─────────────────────────────────────────┤
│ 오늘: 월요일                            │
│                                         │
│ [오전]                                   │
│ 활동: 산책                               │
│ 버튼: [실행] → 실행后 [실행완료] (비활성화)│
│                                         │
│ [오후]                                   │
│ 활동: 독서                               │
│ 버튼: [실행] → 대기                      │
│                                         │
│ [주간계획 추가] 버튼                      │
└─────────────────────────────────────────┘
```

### 3.2 주간 계획 테이블 (상태 표시)

| 요일 | 오전 (AM) | 오후 (PM) |
|------|-----------|-----------|
| 월 | 산책 ✓ | 독서 |
| 화 | 요가 | 운동 |
| 수 | 독서 | - |

**실행된 활동 스타일**:
- ✓ 아이콘 표시
- 비활성화 (opacity-50)
- 옅은 회색 배경

### 3.3 슬롯 상태

| 상태 | 표시 | 비활성화 | 배경 |
|------|------|----------|------|
| **비어있음** | "없음" | - | - |
| **채워짐 (미실행)** | 활동 이름 | - | - |
| **실행 완료** | 활동 이름 ✓ | Yes | 옅은 회색 |

### 3.4 활동 카드

| 버튼 | 기능 | 비고 |
|------|------|------|
| `[주간계획 추가]` | 주간 계획에 활동 추가 | 현재 탭(AM/PM)의 첫 빈 슬롯에 추가 |
| `[실행]` | 오늘의 활동 실행 | 오늘 날짜의 해당 슬롯만 실행 |

### 3.5 초기화 버튼

| 버튼 | 기능 |
|------|------|
| `[주간 초기화]` | 모든 슬롯 초기화 |
| `[오전 초기화]` | AM 슬롯만 초기화 |
| `[오후 초기화]` | PM 슬롯만 초기화 |
