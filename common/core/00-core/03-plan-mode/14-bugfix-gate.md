# 버그/디버깅 계획서 — 증거 우선·원인 확정 게이트

13. **버그/디버깅 계획서는 "증거 우선"·"원인 확정 게이트" 적용 (필수)**:
    - **분류 규칙**: 과거 정상 동작하던 기능이 지금 오동작하면 **무조건 버그(A)**다. 수정에 코드가 추가되더라도 기능개선(B)으로 분류해 버그 템플릿의 재현·근거 규율을 우회하지 말 것.
    - **증상 → 원인 순서 고정**: 계획서는 *관찰된 실패 산출물(실제 에러·로그·실패 입력)*에서 출발한다. 추정 원인에서 출발해 그걸 정당화하는 방향으로 작성하는 것은 지침 위반.
    - **원인 확정 게이트**: 원인은 ① 실제 파라미터로 재현, ② 지목한 코드 줄이 그 실행에서 나쁜 값을 만든다는 관측, ③ 반증 실험 — 3개를 모두 충족할 때만 "원인"으로 적는다. **"코드 존재 확인(grep) ≠ 원인 확정"**. 게이트 통과 전 수정 구현 금지. 상세는 `03-plan-mode/01-type-a-bugfix.md` §1~§2.
